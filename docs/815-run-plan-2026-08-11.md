# 8·15런 실행 계획 (2026-08-11 확정)

**행사**: 2026-08-15(금) 20:15:00 KST 동시 출발 · **8.15km** 그룹대결 · 사전 신청 · 완주 시 **+815P + 기록 카드 815 배지**.
오너 확정: 가상 레이스(각자 출발) 아님 — **진짜 그룹 세션 동시 출발** (파티런/그룹매칭과 동일한 라이브 경험).

## 설계 핵심: 새로 만드는 건 3조각, 나머지는 기존 깔때기가 담당

서버가 신청자들로 **진짜 group 매치 세션**(slotStartAt = 20:15)을 만들어주면, 이후는 전부 기존 경로:
홈 예정 대결 카드 → ≤20초 전 아레나 자동 오픈 → **카운트다운 워밍업**(0b29c01 — GPS 사전 가동, 출발 직후 잠금 안전) →
슬롯 정각 카운트다운 → 라이브 순위판·체크포인트 비교 → 완주 판정(§B4 DNF 봉인 포함) → 그룹 순위 포인트+LP.

### 조각 1 — 이벤트 + 신청 (휴면 오프라인 레이스 시스템 재활용)
- `store.offlineRaceEvents` + join/cancel/hub 라우트 + 관리자 CRUD가 **전부 프로덕션에 살아 있음** (유저 UI만 6/18에 삭제됨).
- 엔티티에 `eventKind: 'live_group'` 필드 추가. 815 이벤트: startsAt=2026-08-15T20:15+09:00, distanceKm=8.15,
  registrationClosesAt=당일 20:00, capacity 넉넉히.
- 클라: 815런 카드(러닝 탭 + 홈) → 상세 화면(취지 카피·D-day·신청자 수·신청/취소). 런마당 화면 패턴 재사용.
- 신청 시 **클라 로컬 알림 20:05 예약** (expo 로컬 노티 — 서버 스케줄러 불필요, 가장 확실).

### 조각 2 — 조 편성 (formation)
- **on-request 스윕** (이 백엔드의 기존 관례: 별도 스케줄러 없음): 20:00(신청 마감) 이후 첫 요청이 편성 실행.
  신청자들이 이벤트 화면을 폴링하고 있으므로 트리거는 사실상 즉시.
- 편성 규칙 (오너 확정 2026-08-11):
  - **조 나누기 없음 — 신청자 전원이 하나의 그룹 세션에서 함께 출발.** GROUP_MATCH_MAX_PARTICIPANTS(30)는
    매치메이킹 intake의 상한이고, 이벤트 세션은 서버 내부 생성이라 적용하지 않는다.
    페이스 클러스터링도 미적용 (축제 = 함께 뛰기).
  - ⚠️ 구현 전 부하 점검 필수: N명이 ~3초마다 progress push = 스토어 행 FOR UPDATE 직렬 쓰기 N/3회/초 +
    세션 내 체크포인트 샘플 누적 + 클라 순위판 N행 렌더. 현실적 참가 규모(수십 명)는 감당 범위로 추정되나,
    finish-window convoy 완화(B-1/2/3)와 체크포인트 그리드가 N=50에서 버티는지 코드로 확인하고,
    필요하면 이벤트 세션 한정 push 간격 완화(3→5초) 같은 안전판을 마련한다.
  - 2명이어도 그룹 세션 성립 (엔진은 test-mode min 2를 이미 지원 — 이벤트 min도 2로).
  - 1명이면: 세션 없이 배지/보너스 자격 러닝으로 안내 (엣지, 구현 시 확정).
- **시간 제약 우회 지점**: `validateMatchSlotInput`은 정각만 허용하지만 그건 *유저 intake* 검증 —
  서버 내부 생성은 통과 안 함. 하류(카운트다운·체크포인트·클라 표시)는 ISO 타임스탬프만 쓰므로 :15 무관.
  단, 클라 슬롯 라벨 포맷터가 정각 가정하는 곳 없는지 구현 때 확인.
- 편성 후: 기존 group 매치 상태 폴이 세션을 자동으로 집어감 (참가자 스캔) → 홈/러닝 탭에 예정 대결 노출.
  이벤트 상세 화면에도 "내 조 + 조원" 표시.

### 조각 3 — 보상 스탬프
- 저장 시 서버가 스탬프: 매치 세션이 815 이벤트 소속이고 완주(distance ≥ 8.15−0.05)면
  `run.raceEvent = { eventId, title: '8·15런', bonusPoints: 815, badge: '815' }`.
- 회계는 **경찰과 도둑런과 동일 구조** (지급 함수 없음 — points.mjs가 재계산에 합산). 파생 잔액이라 소급 안전.
- 클라: 기록 카드 + 상세에 815 배지(태극 모티프) 렌더. 그룹 순위 포인트(25/20/15/10)·LP는 기존 그대로 얹힘.
