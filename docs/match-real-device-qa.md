# Match Real Device QA

## 목적
이 문서는 `RunningGround`의 매칭 흐름을 실제 기기에서 끝까지 검증할 때 쓰는 실전 순서야.

지금 목표는 아래 일곱 가지다.
- `1대1 테스트 매칭`이 바로 잡히는지
- `그룹 테스트 매칭`이 바로 잡히는지
- `예약 매칭`이 정상적으로 잡히는지
- `카운트다운`이 홈과 러닝 화면에 같이 보이는지
- `대결 시작`이 자연스럽게 전환되는지
- `대결 종료` 후 결과 화면이 자연스러운지
- `테스트 대결 그만`으로 혼자 러닝으로 빠질 수 있는지

같이 열어두면 좋은 문서:
- [testflight-real-device-qa.md](/docs/testflight-real-device-qa.md)
- [android-install-and-first-sync.md](/docs/android-install-and-first-sync.md)

## 시작 전 준비
### 1. 기기 조합
권장 조합은 이거야.
- iPhone 1대
- Galaxy 1대
- 서로 다른 계정 2개

테스트 매칭만 빨리 볼 때는 같은 기기 1대로도 가능하지만, 예약 매칭과 실제 라이브 동기화는 두 기기가 더 안정적이다.

### 2. 앱 상태
- 앱을 완전히 종료
- 10초 정도 기다리기
- 다시 실행
- 필요하면 한 번 더 종료 후 재실행

### 3. 서버 상태
매칭 QA 직전에는 대기열과 세션이 비어 있는 편이 좋다.
이번 시작 시점 기준으로 `preview / production` 모두 `duel queue 0`, `group queue 0`, `sessions 0` 상태로 맞춰둔 뒤 시작하는 걸 권장한다.

## 추천 계정 구성
### 계정 A
- iPhone 로그인
- 테스트 매칭 / 예약 매칭 생성 담당

### 계정 B
- Galaxy 로그인
- 상대 참가 / 그룹 보강 / 라이브 비교 담당

## 1차 게이트: 1대1 테스트 매칭
### 순서
1. `런닝 -> 1대1 매치`
2. `1대1 테스트 매칭` 누르기
3. 30초 카운트다운 진입 확인
4. 카운트다운 종료 후 대결 화면 진입 확인
5. `대결 보기`, `순위 보기`, `기록 보기`를 좌우로 넘겨보기
6. `기록 보기`에서 `테스트 대결 그만` 누르기

### 통과 기준
- 다른 기기가 없어도 바로 테스트 대결이 잡힌다
- `WAITING`에 오래 머무르지 않는다
- 30초 카운트다운이 보인다
- 시작 후 `대결 보기 / 순위 보기 / 기록 보기`가 모두 열린다
- `테스트 대결 그만`을 누르면 혼자 러닝으로 자연스럽게 이어진다

## 2차 게이트: 그룹 테스트 매칭
### 순서
1. `런닝 -> 그룹 대결`
2. `그룹 테스트 매칭` 누르기
3. 30초 카운트다운 진입 확인
4. 카운트다운 종료 후 그룹 대결 화면 진입 확인
5. `대결 보기`, `순위 보기`, `기록 보기` 확인

### 통과 기준
- 2명 미만이어도 더미 러너가 채워져 바로 시작된다
- 그룹 화면에 여러 러너가 보인다
- `순위 보기`에서 순위 / 진행 바 / 페이스 / 남은 km가 같이 보인다
- `앞 사람 / 뒤 사람` 정보와 라이브 배너가 납득 가능하다

## 3차 게이트: 예약 1대1 매칭
### 순서
1. `런닝 -> 1대1 매치`
2. 날짜 선택
3. `오전 / 오후` 선택
4. 시간대 선택
5. `1대1 매칭 찾기` 누르기
6. 홈과 러닝 화면에 예약 카드가 생기는지 확인

### 통과 기준
- 오늘부터 1주일 안 슬롯만 고를 수 있다
- 출발 30분 전 슬롯은 `마감`으로 보인다
- 이미 다른 매치가 있으면 새 매칭이 막힌다
- 예약 카드에 `몇 월 몇 일 / 요일 / 시간 / 상대`가 보인다

## 4차 게이트: 예약 그룹 매칭
### 순서
1. `런닝 -> 그룹 대결`
2. 날짜 선택
3. `오전 / 오후` 선택
4. 시간대 선택
5. `그룹 매칭 찾기` 누르기

### 통과 기준
- 예약 카드에 `몇 명 그룹인지` 보인다
- 출발 1시간 전까지는 취소 가능하다
- 출발 1시간 안쪽이면 취소 버튼 대신 안내 문구가 보인다

## 5차 게이트: 카운트다운
### 순서
1. 예약된 매치를 시작 10분 안쪽 슬롯으로 잡기
2. 홈에서 예약 카드 확인
3. 러닝 화면에서도 같은 예약 카드 확인
4. 시작 30초 전 오버레이 진입 확인

### 통과 기준
- 시작 10분 전부터 `MM:SS` 카운트다운이 보인다
- 시작 30초 전부터 풀스크린 카운트다운 오버레이가 보인다
- 홈과 러닝 화면의 남은 시간이 크게 어긋나지 않는다

## 6차 게이트: 시작과 종료
### 순서
1. 카운트다운 종료 후 대결 시작
2. 1대1은 `LIVE GAP` 카드 확인
3. 그룹은 `순위 보기`와 라이브 상태 배너 확인
4. 적당한 시점에 러닝 종료
5. 결과 저장

### 통과 기준
- 1대1은 `승리 / 패배 / 무승부` 중심으로 결과가 보인다
- 그룹은 `몇 명 중 몇 위`로 결과가 보인다
- 포인트 규칙이 맞다
  - 1대1 승리 `20P`
  - 1대1 패배 `10P`
  - 1대1 무승부 `15P`
  - 그룹 1등 `25P`
  - 그룹 2등 `20P`
  - 그룹 3등 `15P`
  - 그룹 4등 이하 `10P`

## 7차 게이트: 예외 처리
### 확인할 것
- 이미 예약된 매치가 있을 때 다른 매치 신청 차단
- 테스트 대결 중 앱을 백그라운드로 보냈을 때 상태 배너
- 한쪽에서 대결을 포기했을 때 상대 화면 반영
- 앱을 강제 종료했다가 다시 열었을 때 복귀 흐름

## 실패하면 남길 것
문제 생기면 아래만 적어두면 다음 수정이 빨라진다.
- 기기: `iPhone 16 Pro`, `Galaxy S24`
- 계정: `A / B`
- 매치 종류: `1대1 테스트`, `그룹 테스트`, `1대1 예약`, `그룹 예약`
- 시점: `매칭 전`, `카운트다운`, `시작 직후`, `종료 직후`
- 실제 결과:
  - WAITING에 멈춤
  - 카운트다운 불일치
  - 시작 전환 안 됨
  - 결과 화면 이상
  - 포인트 이상
