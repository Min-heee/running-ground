# Android Live Match Performance QA

Android 대결 화면 렉을 비교할 때는 개발 빌드에서 `대결 보기` 카드 안의 `ANDROID QA PERF` 패널을 확인합니다.

## 패널 값

- `FPS`: 최근 5초 동안의 대략적인 화면 frame 수입니다.
- `평균 FPS`: 현재 대결 화면에서 쌓인 샘플 평균입니다.
- `렌더`: 최근 5초 동안 `LiveMatchArena`가 다시 렌더링된 횟수입니다.
- `평균 렌더`: 현재 대결 화면 샘플의 평균 렌더 횟수입니다.
- `참가`: 전체 참가자 수입니다.
- `표시`: Android 경량 모드에서 실제 화면에 렌더링하는 참가자 수입니다.
- `샘플`: 5초 단위로 누적된 QA 샘플 수입니다.

## 테스트 방법

1. Android 개발 빌드에서 파티런 1대1을 시작합니다.
2. 카운트다운 후 `대결 보기` 화면에 들어가서 10초 이상 둡니다.
3. `FPS`, `렌더`, `참가`, `표시` 값을 기록합니다.
4. 같은 방식을 iOS 또는 다른 Android 기기와 비교합니다.
5. 그룹 30명 테스트에서는 `참가 30명`, `표시 N명`이 보이는지 확인합니다.

## 판단 기준

- FPS가 45 이상이면 대체로 양호합니다.
- FPS가 30 근처로 떨어지면 화면 렌더링 또는 리스트 렌더링이 무거운 상태입니다.
- `렌더`가 5초에 10회 이상이면 상태 업데이트가 너무 자주 화면까지 내려오는지 확인합니다.
- `참가`는 많은데 `표시`가 낮게 유지되면 Android 경량 모드가 정상 작동 중입니다.

## 로그 위치

- 화면 패널: `LiveMatchArena` 카드 안 `ANDROID QA PERF`
- 콘솔 로그: `[LiveMatchPerf] duel-arena ...` 또는 `[LiveMatchPerf] group-arena ...`
- 메모리 QA 로그: `src/components/matches/liveMatchPerfQaLog.ts`
