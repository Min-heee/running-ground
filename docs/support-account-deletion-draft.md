# RUNNIGAPP 지원 및 계정 삭제 안내 초안

이 문서는 Google Play의 `앱 외부 계정 삭제 링크` 와 App Store 심사 대응에 맞춰 공개 웹페이지로 옮기기 위한 초안입니다.

권장 게시 URL 예시:
- 지원 페이지: `https://[도메인]/support`
- 계정 삭제 안내: `https://[도메인]/account-deletion`

중요:
- Google Play는 계정 생성 앱에 대해 `앱 밖에서도 접근 가능한 삭제 요청 링크` 를 요구합니다.
- 링크는 실제로 열려야 하고, 앱 또는 개발자명을 포함해야 하며, 계정 삭제 방법이 눈에 띄게 보여야 합니다.

---

## 1. 지원 페이지 초안

### RUNNIGAPP 지원 안내

안녕하세요. RUNNIGAPP 지원 페이지입니다.

문의가 필요하시면 아래 채널로 연락해주세요.

- 서비스명: RUNNIGAPP
- 운영자/팀명: `[운영자명 또는 팀명]`
- 지원 이메일: `[support@your-domain.com]`
- 응답 목표 시간: `[예: 영업일 기준 2~3일 이내]`

문의 예시:
- 로그인/회원가입 문제
- 기록 연동 문제
- 친구/랭킹 표시 오류
- 데이터 수정 또는 삭제 문의
- 스토어 심사 관련 문의

---

## 2. 계정 삭제 안내 페이지 초안

### RUNNIGAPP 계정 삭제 안내

RUNNIGAPP은 사용자가 계정을 직접 삭제할 수 있도록 앱 내 탈퇴 기능을 제공합니다.

앱에서 삭제하는 방법:
- `마이페이지 > 회원 탈퇴`

앱 접근이 어려운 경우:
- 아래 이메일로 계정 삭제 요청을 보낼 수 있습니다.
- 이메일: `[support@your-domain.com]`

요청 시 확인에 도움이 되는 정보:
- 아이디
- 닉네임
- 가입 시 사용한 휴대폰 번호 일부
- 삭제를 원하는 계정 설명

---

## 3. 삭제 시 처리되는 데이터 초안

계정 삭제 요청이 완료되면 아래 데이터가 삭제 대상이 됩니다.

- 계정 정보
- 로그인 세션
- 러닝 기록
- 친구 관계 및 친구 요청
- 기록 연동 가져오기 이력
- 레이스 참가 정보
- 리워드/교환 관련 사용자 기록

삭제 후에는 계정 복구가 제한될 수 있습니다.

---

## 4. 예외 보관 항목 안내 초안

법령, 보안, 사기 방지 또는 분쟁 대응 목적으로 일부 정보를 일정 기간 보관해야 한다면 여기에 명시합니다.

예시 형식:
- `[예외 보관 데이터]`: `[보관 이유]`
- `[보관 기간]`: `[예: 최대 30일 또는 관련 법령상 기간]`

예외가 없다면 다음처럼 간단히 적습니다.

- RUNNIGAPP은 법령상 또는 보안상 별도 보관이 필요한 경우를 제외하고, 계정 삭제 완료 후 관련 데이터를 삭제합니다.

## 5. 사용자에게 보여줄 짧은 안내 문구 예시

### 지원 페이지용 짧은 문구
RUNNIGAPP 사용 중 문제가 있거나 도움이 필요하시면 아래 이메일로 문의해주세요.

### 계정 삭제 페이지용 짧은 문구
앱에서는 `마이페이지 > 회원 탈퇴` 에서 계정 삭제를 요청할 수 있습니다. 앱에 접근할 수 없는 경우 아래 지원 이메일로 삭제 요청을 보내주세요.
