## 2. 어떤 정보를 처리하나요

RUNNIGAPP은 아래 정보를 처리할 수 있습니다.

### 2-1. 계정 생성 및 운영 정보
- 아이디
- 닉네임
- 이름(비공개)
- 휴대폰 번호
- 생년월일
- 시/도, 시/군/구, 상세 주소
- 대학교 정보
- 친구 태그

### 2-2. 러닝 및 활동 정보
- 러닝 날짜
- 거리
- 페이스
- 러닝 횟수
- 포인트, 연속 러닝 정보
- 친구 랭킹 / 지역 리그 / 대학교 리그 산정에 필요한 활동 정보

### 2-3. 연동 및 기기 기록 정보
사용자가 권한을 허용한 경우 아래 기록을 가져올 수 있습니다.

- Apple 건강(HealthKit)에서 읽은 러닝 운동 기록
- 걷기/달리기 거리
- 심박수
- 기타 사용자가 명시적으로 공유 허용한 러닝 관련 기록

현재 iPhone 기준 주요 연동 흐름은 `Nike Run Club -> Apple 건강 -> RUNNIGAPP 가져오기` 입니다.

### 2-4. 기술적 운영 정보
- 로그인 세션 정보
- 앱 연동 상태
- 오류 확인 및 운영 안정화를 위한 최소한의 서버 로그

## 3. 정보를 왜 사용하나요

RUNNIGAPP은 다음 목적 범위에서 정보를 사용합니다.

- 회원가입 및 로그인 처리
- 사용자 본인 확인 및 계정 보호
- 러닝 기록 저장 및 내 활동 화면 제공
- 친구 경쟁, 지역 리그, 대학교 리그 순위 계산
- 기록 연동 상태 확인 및 중복 가져오기 방지
- 포인트, 교환, 오프라인 레이스 등 앱 기능 제공
- 고객 문의 응대, 운영 공지, 서비스 안정화

## 4. 어떤 정보가 공개되나요

앱 내 공개 화면에는 기본적으로 아래 정보만 노출됩니다.

- 닉네임
- 친구 태그
- 지역/대학교 랭킹 참여 정보
- 러닝 거리, 포인트 등 경쟁용 활동 정보

아래 정보는 공개하지 않습니다.

- 이름
- 휴대폰 번호
- 상세 주소
- 생년월일

---

## 5. 건강 데이터 처리 안내

RUNNIGAPP은 사용자가 권한을 허용한 경우에만 건강 데이터를 읽습니다.

- 건강 데이터는 사용자의 러닝 기록을 가져와 내 활동 및 랭킹에 반영하기 위해 사용됩니다.
- 건강 데이터 접근 권한은 기기 설정에서 언제든지 변경할 수 있습니다.
- 사용자가 연동 기능을 쓰지 않으면 건강 데이터를 읽지 않습니다.

Apple 심사 대응용 메모로는 다음 설명이 일관됩니다.

- 사용자가 외부 러닝앱에서 기록한 운동이 Apple 건강에 반영되면, RUNNIGAPP이 이를 읽어와 활동과 경쟁 화면에 반영합니다.
