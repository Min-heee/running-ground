# Store Submission Draft

## 목적
이 문서는 `RUNNIGAPP` 출시 직전에 App Store Connect / Play Console 에 넣을 문구와 체크리스트를 빠르게 정리하기 위한 초안이다.

아직 법률 문서나 실제 운영 도메인이 완전히 고정되기 전 단계이므로, 아래 내용은 `출시 직전 최종 확인용 초안`으로 사용한다.

## v1에서 실제로 약속해도 되는 것
출시 문구는 아래 범위를 기준으로 잡는 것이 안전하다.

- 계정 생성과 로그인
- 내 프로필/지역/대학교 설정
- 친구 추가와 친구 랭킹 비교
- 내 활동/러닝 기록 확인
- iPhone 기준 Apple Health 경유 기록 가져오기
- 지역/대학교 기반 경쟁 화면

아직 문구에서 과하게 약속하지 않는 편이 좋은 것:

- 여러 외부 러닝 앱의 완전한 직접 연동
- 실시간 GPS 네비게이션 중심 러닝 측정
- 실제 커머스 결제형 마켓
- 모든 플랫폼에서 동일한 건강 데이터 연동 완성도

## App Store Connect 초안

### 앱 이름
- `RUNNIGAPP`

### 부제
- `러닝 기록이 경쟁이 되는 러닝 앱`

### 프로모션 텍스트
- `친구, 지역, 대학교 랭킹에서 내 러닝 기록을 바로 비교하고 경쟁해보세요.`

### 키워드
- `러닝,달리기,운동기록,친구랭킹,러닝기록,건강연동,대학리그,지역리그`

### 설명
```text
RUNNIGAPP은 내 러닝 기록을 혼자 보관하는 데서 끝나지 않고, 친구와 지역, 대학교 안에서 바로 비교하고 경쟁할 수 있도록 만든 러닝 앱입니다.

러닝을 마친 뒤 기록을 가져오면 홈에서 내 활동 요약을 확인하고, 친구 랭킹에서 이번 주 거리와 포인트를 비교할 수 있습니다. 지역 리그와 대학교 리그에서도 현재 순위와 흐름을 한눈에 볼 수 있어 매일의 러닝이 더 분명한 목표로 이어집니다.

지금 버전은 가장 핵심적인 흐름에 집중했습니다. 계정 생성, 프로필 설정, 친구 추가, 내 활동 확인, 기록 가져오기, 랭킹 비교를 빠르고 간단하게 사용할 수 있습니다.
```

### 1.0.0 버전 업데이트 문구 초안
```text
RUNNIGAPP 첫 출시 버전입니다.

- 친구 러닝 랭킹과 내 활동 확인
- 지역/대학교 경쟁 화면
- iPhone Apple Health 기반 기록 가져오기
- 프로필, 연동 상태, 기본 설정 관리
```

### App Review 메모 초안
```text
안녕하세요. RUNNIGAPP은 러닝 기록을 기반으로 친구/지역/대학교 경쟁을 제공하는 앱입니다.

테스트 시 기본 흐름:
1. 회원가입 또는 로그인
2. 홈 진입
3. 친구 탭 / 리그 탭 / 내 활동 확인

건강 데이터 관련:
- iPhone에서는 Apple Health를 통해 러닝 기록을 가져옵니다.
- 건강 권한은 기록 가져오기 기능에만 필요합니다.
- 건강 권한을 허용하지 않아도 로그인, 홈, 친구, 리그, 프로필 흐름은 확인할 수 있습니다.

현재 소셜 로그인 버튼은 활성화된 실제 로그인 방식이 아니며, 계정 로그인/회원가입 흐름을 사용해 주세요.
```

### Apple Health 관련 설명 초안
이 문구는 리뷰 노트나 내부 제출 메모에 함께 붙여두면 좋다.

```text
러닝 기록 가져오기 테스트는 다음 순서가 가장 안정적입니다.
1. Nike Run Club 등으로 러닝 기록
2. Apple 건강 앱에 운동 데이터 반영 확인
3. RUNNIGAPP에서 기록 가져오기 또는 동기화 실행
```

3. 리그 화면(지역 또는 대학교)
4. 내 활동 화면
5. 기록 연동 관리 화면

## Play Console 초안

### 앱 이름
- `RUNNIGAPP`

### 짧은 설명
- `러닝 기록으로 친구, 지역, 대학교와 경쟁하는 러닝 앱`

### 전체 설명
```text
RUNNIGAPP은 러닝 기록을 기반으로 친구와 경쟁하고, 지역과 대학교 안에서 내 순위를 확인할 수 있는 러닝 앱입니다.

앱에서 계정을 만들고 프로필을 설정한 뒤 기록을 가져오면, 홈에서 내 활동 요약을 보고 친구 랭킹에서 이번 주 거리와 포인트를 비교할 수 있습니다. 지역 리그와 대학교 리그를 통해 내가 속한 그룹 안에서 얼마나 달리고 있는지도 쉽게 확인할 수 있습니다.

핵심 기능
- 친구 추가와 친구 랭킹 비교
- 내 활동과 러닝 기록 확인
- 지역/대학교 리그 확인
- 연동 상태와 기록 가져오기 관리

현재 버전은 가장 중요한 경쟁 흐름에 집중한 첫 출시 버전입니다.
```

### Play Store 스크린샷 구성
- 홈
- 친구 랭킹
- 지역/대학교 리그
- 내 활동
- 연동 관리

## 개인정보/권한 정리 초안
이 부분은 실제 정책 문서 작성 전에 내부 확인용으로 쓴다.

### 수집 또는 처리하는 데이터 초안
- 계정 정보: 아이디, 닉네임, 이름, 지역, 대학교
- 앱 내 활동 데이터: 러닝 기록, 거리, 페이스, 포인트, 연동 상태
- 선택적 건강 데이터: 사용자가 권한을 허용한 경우 가져온 운동 기록

### 권한 사용 목적 초안
- 건강 데이터: 사용자의 러닝 기록을 가져와 내 활동과 랭킹에 반영하기 위해 사용
- 보안 저장소: 로그인 세션 유지

### 주의
실제 App Privacy / Data Safety 작성 전에는 아래를 다시 확인해야 한다.

- 서버에 실제 저장되는 필드
- 제3자 SDK 사용 여부
- 계정 삭제 처리 여부
  현재 앱 경로: `마이페이지 > 회원 탈퇴`
- 건강 데이터가 기기에서만 쓰이는지, 서버까지 올라가는지
